# Cortex-M labs

No bare-metal lab is included.

- `01_exception_frame`: inspect the hardware exception frame.
- `02_msp_psp`: verify tasks/Thread mode on PSP and handlers on MSP.
- `03_svc`: study first-task startup through exception return.
- `04_pendsv`: save and restore two minimal contexts.

After lab 04, continue development directly in the canonical ntos kernel.
